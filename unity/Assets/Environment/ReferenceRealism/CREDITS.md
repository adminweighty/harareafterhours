# Reference-led First Street assets

Primary location references supplied by the user: 10_First_Street_Day.png,
11_First_Street_Night.png; daylight context: 12_Jason_Moyo_Avenue.png.
These images remain references, not textures pasted onto building geometry.

Photographic wall maps: Concrete Wall 004, Charlotte Baglioni (photography),
Dario Barresi (processing), https://polyhaven.com/a/concrete_wall_004

Leaf colour/alpha and bark colour: Jacaranda Tree, Rico Cilliers, guidance by
Rob Tuytel, https://polyhaven.com/a/jacaranda_tree
Only these maps are used; the full source model is not shipped. The mobile
tree is newly authored with LOD budgets of 1320 / 880 / 650 triangles.

Both sources are CC0: https://polyhaven.com/license
Maps are unmodified; Unity import settings provide mobile compression/mipmaps.
The building finish, vendor positions and tree placement are inferred from
limited reference views, not exact surveyed reconstructions.
