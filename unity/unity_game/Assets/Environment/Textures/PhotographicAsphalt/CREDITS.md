# Photographic road surface

Asphalt 03, Poly Haven: https://polyhaven.com/a/asphalt_03
Photography: Charlotte Baglioni. Processing: Dario Barresi.
CC0: https://polyhaven.com/license

Unmodified 1K JPG diffuse, OpenGL normal and roughness maps downloaded
from the official Poly Haven asset downloads on 2026-09-23.
Physical repeat: 2.05 metres (asset API dimensions: approximately 2050 mm).
Unity imports colour as sRGB, normal as NormalMap, roughness as linear.
Mobile settings: ASTC 6x6, mipmaps, trilinear filtering, anisotropy 4.
This is a photographed asphalt material, not a photograph of a Harare street.
Existing road geometry, collisions, markings and city layout are unchanged.
