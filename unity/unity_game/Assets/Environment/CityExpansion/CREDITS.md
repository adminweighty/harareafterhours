# City expansion sources

- Architecture: user's `Harare_Game_Environment_20` reference images. Original game-ready geometry; not an exact survey or a claim of real-world street coordinates.
- Sky: **Kloofendal 48d Partly Cloudy (Pure Sky)**, Greg Zaal (original), Jarod Guest (sky edits), Poly Haven, CC0. https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky
  - Original unmodified 2K HDR source, 5,451,493 bytes.
  - MD5: `2eba3a4d7eeb23cbfbeca364c97e7980`.
  - Imported by Unity as a mipmapped 512-face HDR cubemap. Not photographed in Harare; used only for sky/clouds/reflection lighting.
  - License: https://polyhaven.com/license
- Existing photographic concrete, asphalt, jacaranda bark/leaves reused from the preceding environment passes; see `Assets/Environment/ReferenceRealism/CREDITS.md` and existing texture credit files.
- Palm silhouette is original low-polygon geometry guided by supplied image 17. Bark reuses the existing tree material as an approximation; not a botanical scan.
